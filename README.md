# Интеллектуальная система управления БПЛА (Next.js)

Веб-приложение по теме «Проектирование интеллектуальных систем управления».

## Страницы

| Путь | Содержание |
|---|---|
| `/` | Схема системы (рисунок 1), кликабельные этапы, таблица методов ИИ |
| `/etap-1` | Подготовка данных и ПО: источники данных, датасеты, фильтрация шума (OpenCV-аналоги), нормализация, коррекция GPS |
| `/etap-2` | Генерация траектории: круг, восьмёрка, произвольная (A* + 2-opt), покрытие поля |
| `/etap-3` | Управление полётом: ПИД-регулятор в реальном времени, облёт препятствий, PPO |
| `/etap-4` | Обнаружение объектов: YOLOv8, NMS, Precision/Recall/AP, координаты объектов |
| `/etap-5` | Создание карты: SLAM (сопоставление сканов + сетка занятости), 2D/3D карта |
| `/etap-6` | Изменение координат: WGS-84 → ECEF → ENU, UTM, DGPS + фильтр Калмана |
| `/etap-7` | Принятие решений: нечёткая логика Мамдани, Decision Tree / Random Forest, SVM, регрессия |
| `/program` | Программа по блок-схеме (рисунок 2): код Python, выполнение, CNN–LSTM + EKF, 15 автотестов, анализ |
| `/ndvi` | Расчёт NDVI и управление моментом съёмки (рисунок 3), загрузка собственного снимка |

Все алгоритмы выполняются в браузере на JavaScript без внешних библиотек (только `next`, `react`, `react-dom`).

## Запуск локально

```bash
npm install
npm run dev        # http://localhost:3000
```

## Деплой на Vercel

1. Загрузите папку проекта в репозиторий GitHub.
2. На vercel.com → **Add New… → Project** → выберите репозиторий.
3. Framework Preset определится как **Next.js**; настройки по умолчанию. Нажмите **Deploy**.

Или через CLI: `npm i -g vercel && vercel --prod` в папке проекта.
